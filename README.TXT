Food Delight - Restaurant Website

Overview

Food Delight is a modern, stylish, and fully responsive restaurant website that provides an elegant online presence for a dining experience. The website includes various sections such as Home, Menu, Reservations, Events, Contact, About Us, Gallery, and Special Offers.

To run:- 
https://fooddelightrestraunt.netlify.app/

Features

Fully Responsive Design – Optimized for all screen sizes

Dynamic Menu Page – Showcases dishes with descriptions and prices

Reservations Page – Allows users to book tables seamlessly

Events Page – Highlights special events with booking options

Gallery Page – Displays beautiful images of the restaurant ambiance and dishes

Special Offers Section – Displays limited-time deals and discounts

Consistent Header and Footer – Provides easy navigation throughout the site

Technologies Used

HTML5 – Structuring the website

CSS3 – Styling and animations

JavaScript – Interactive features

Setup Instructions



Navigate to the project folder:

cd food-delight

Open index.html in a browser to view the website.

Deployment

You can deploy this project using GitHub Pages or a hosting service like Netlify or Vercel.
